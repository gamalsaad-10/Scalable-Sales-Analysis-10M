# 📊 Large-Scale Trading Sales Analysis (10M+ Rows)

## 📋 Project Overview
This project presents a comprehensive analysis of a **Trading Company** dataset spanning **9 years** of historical sales. With over **10 million rows** of data, the primary focus was on building a high-performance analytical model to track KPIs across 4 major categories: **Accessories, Bikes, Clothing, and Components**.

## 🛠️ Tech Stack & Skills
- **Power BI / Power Pivot:** Used for advanced data modeling and visualization.
- **DAX (Data Analysis Expressions):** Developed **20+ complex measures** for deep analytical insights.
- **Power Query:** Executed ETL processes to clean and transform raw data.
- **Statistical Analysis:** Applied statistical methods to calculate variances and identify trends.

## 🔑 Key Metrics & Features
- **Core KPIs:** Total Revenue, Total Quantities, Number of Transactions.
- **Averages:** Average Price, Average Sold Quantities, Average Revenue per Transaction.
- **Time Intelligence:** Annual, Quarterly, and Monthly sales variance analysis.
- **Data Modeling:** Optimized **Star Schema** to handle 10M+ records with high responsiveness.

## 🚀 Impact & Insights
- Successfully identified seasonal trends and performance fluctuations over a nearly decade-long period.
- Simplified massive datasets into an interactive dashboard for data-driven decision-making.
